# GeoINR
Use different coordinate MLP networks for Geophysics!

By parameterising a potential field grid with a Nerual Network, perhaps we can calculate some functions analytically in a continuous domain. And maybe that would be cool!

Original SIREN implementation by Sitzmann et al., available at https://github.com/vsitzmann/siren

Original WIRE implementation by Ramasinghe et al., available at https://github.com/vishwa91/wire/
